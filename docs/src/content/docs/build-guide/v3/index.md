このページは [Booth](https://cormoran707.booth.pm/items/8132198) で配布中の DYA Dash v3 (=rev3) 向けの組み立てガイドです。

はんだ付けの必要な v2 (=rev2) 向けのガイドは [こちら](/dya-dash-keyboard/build-guide/v2) をご覧ください。

:::caution
v3 は v2 から内部構造が大きく変わっています。v3 向けのファームウェアは v2 とは互換性がないので注意してください。
また、v3 は XIAO plus のみ対応です。v2 は通常の XIAO のみ対応です。
:::

## 組み立ての流れ

1. **[事前準備](/dya-dash-keyboard/build-guide/v3/preparation)** - 必要な部品と工具の確認
2. **[ファームウェア](/dya-dash-keyboard/build-guide/v3/firmware)** - XIAO へのファームウェア書き込み
3. **[ケース組み立て](/dya-dash-keyboard/build-guide/v3/case-assembly)** - ケースの組み立てと完成

## 完成イメージ

ビルドガイドでは以下の例を解説します。

- 左小指にロータリーエンコーダー（エンコーダー別途購入 & 半田付け必要）
- 左親指スイッチモジュール
- 右親指トラックボールモジュール

## 困ったときは

- 部品が不足している場合は、購入プラットフォームのメッセージ機能でお早めにご連絡ください
  - キーケットで購入した場合も booth のメッセージ機能でご連絡ください
- 組み立てに失敗した場合や、なぜかうまく動かない場合も可能な限りサポートしますのでお気軽にご相談ください。
